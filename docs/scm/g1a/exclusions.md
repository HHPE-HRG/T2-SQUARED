# G1A governed exclusions

Steward of this list: G1A discovery author (Cursor agent). Independent A7 must accept or reject these exclusions. Rejecting an exclusion reopens G1A for that class or path.

| ID                | Item                                                                            | Rationale                                                                                                                                                                                                       | Steward                               |
| ----------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| EX-CLI-STE        | `scripts/asd-ste100/**`                                                         | T2-owned CLI. `apps/server` does not import or spawn it. Not originating/terminating/crossing a server component boundary in this host.                                                                         | discovery author; A7 review           |
| EX-CLI-REGISTRY   | `scripts/work-registry/**`                                                      | Same as EX-CLI-STE.                                                                                                                                                                                             | discovery author; A7 review           |
| EX-RELAY-DEPLOY   | `infra/relay` process                                                           | Separate deployable. Server _talks to_ relay over HTTP/connect APIs already listed under external-transport. Do not inventory the relay’s internal bus as T2-host communication.                                | discovery author; A7 review           |
| EX-CLIENT-RUNTIME | `packages/client-runtime`, `apps/desktop`, `apps/mobile`, `apps/web` **source** | Peer client trees. Not loaded into the server Node process. Server-terminating RPC/HTTP remains in scope. Distinct from packages the server **does** load (`@t3tools/shared`, `effect-acp`, …).                 | discovery author; A7 review           |
| EX-WEB-BUILD      | `@t3tools/web` workspace package                                                | Listed in server `package.json` for Vite `dependsOn` build only. No `apps/server/src` import. Built files may be served as `staticDir` (class 8 HTTP). Package source is not process-loaded communication code. | discovery author; A7 review           |
| EX-TEST-PUBSUB    | `PubSub` / `Queue` constructed only in `*.test.ts`                              | Not shipped communication.                                                                                                                                                                                      | discovery author; A7 review           |
| EX-PURE-LOCAL     | Pure computation and component-private memory                                   | Requirements R11a counterexamples.                                                                                                                                                                              | discovery author; A7 review           |
| EX-HHPE-REDIS     | HHPE seed Redis                                                                 | Redis and B0/Kafka are empty canonical HHPE seeds. No live T2-host equivalent was found. They remain unresolved in HHPE and are outside this host-bounded G1 inventory; no T2 steward is assigned.              | none (non-host; unresolved HHPE seed) |
| EX-HHPE-KAFKA     | HHPE seed B0/Kafka                                                              | Same wording as EX-HHPE-REDIS.                                                                                                                                                                                  | none (non-host; unresolved HHPE seed) |
